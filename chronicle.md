<h1>Летопись топа вещей</h1>

<h3>Топ вещей v0</h3>

Создание текстового файлика с 10 вещами. Заносили вручную, голосовали вживую. 

<h3>Топ вещей v1</h3>

Файлик перенесён на сервер, Добавление и голосование автоматизированы. Интерфейс через тг-бота.


<h3>Топ вещей v2.0</h3>

Появление РБД sqlite3 и единого бэкенда на Django. Бот обращается по API. SSR веб-страничка с глобальным топом + админка. Регистрация домена top-of-things.ru, прокси-сервер nginx. Добавлены категории вещей.

<h3>Топ вещей v2.0.1 - latest</h3>

Добавлена аутентификация методов, SSL-сертификат и домен topofthings.ru.

<h3>Топ вещей v2.0.2 - dev</h3>

Сущность Battle в БД, сохранение истории битв. Соответствующие API-методы. Команда /battle в боте.
Добавление timestamp и полей авторства в БД.
Файловая декомпозиция в коде. 
API-методы для категорий, фильтр по категории в глобальном топе.

<h3>Планы</h3>

- Интеграция с API Telegraph для больших локальных топов.
- Переезд фронтенда на React SPA
- Автоматизация развертывания (docker)
- Пагинация
- Пользователи. Авторизация на сайте. Интерфейс батлов и добавления вещей. Интерфейс администратора.
- Страничка одной вещи, страничка "о проекте"
- S3-хранилище. Мультимодальные вещи
- realtime web (для начала просто long poll)
- Миграция базки на PostgreSQL
- Турниры вещей. Швейцарки, круговики, арены
- Рекомендации и похожие вещи по embedding. Развернуть что-то маленькое BERT-подобное
- мобильные приложения
